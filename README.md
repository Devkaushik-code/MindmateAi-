🧠 MindMate AI

Your Private AI Reflection Space

MindMate AI is a web-based journaling and AI reflection companion designed to give users a simple, private space to express their thoughts, track their moods, maintain journaling habits, and have supportive conversations with an AI companion.

---

✨ Features

- 🔐 Login & Signup — Simple account system for the prototype
- 📖 Private Journaling — Write and save personal reflections
- 😊 Mood Tracking — Choose a mood while journaling
- 🔎 Journal Search — Quickly find previous journals
- ✏️ Edit & Delete — Manage saved journal entries
- 🔥 Streak Tracking — Encourage consistent journaling habits
- ✨ AI Reflection Chat — Talk with MindMate about your thoughts and feelings
- 💬 Chat Persistence — Conversations remain available after refreshing
- 🌙 Light & Dark Mode — Choose a comfortable visual theme
- 👤 Profile — View account information and log out
- 📱 Mobile Friendly — Designed to work well on smartphones

---

🤖 AI Reflection

MindMate provides supportive, reflective responses designed to help users:

- Express their thoughts
- Reflect on their feelings
- Break overwhelming situations into smaller steps
- Think about goals and future concerns
- Explore their emotions without judgment

The prototype includes a demo AI response system and can be connected to Google's Gemini API.

«Note: MindMate is a reflection companion, not a therapist, doctor, or professional mental-health service.»

---

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Gemini API integration
- Responsive Web Design

---

🔒 Privacy

For the current prototype, journal entries, account information, and chat history are stored locally in the user's browser using LocalStorage.

No real API key should be exposed in the frontend or uploaded to a public repository.

For a production version, authentication and data storage should be moved to a secure backend/database.

---

🚀 How to Run

1. Download or clone this repository.
2. Open "index.html" in a browser.

For the Gemini AI integration, configure the API through a secure backend before using the application in production.

---

🎯 Project Goal

The goal of MindMate AI is to make self-reflection easier and more accessible by combining digital journaling with AI-powered conversation.

Instead of simply recording thoughts, users can interact with their reflections and receive supportive prompts that encourage them to think, understand, and move forward.

---

🔮 Future Improvements

- Secure backend authentication
- Cloud synchronization across devices
- Secure database storage
- More advanced AI personalization
- Mood analytics and insights
- Weekly/monthly reflection reports
- Voice journaling
- PWA/mobile app support
- Stronger privacy and security controls

---

⚠️ Disclaimer

MindMate AI is an educational/ideathon prototype.

It does not provide medical, psychological, or professional advice. Users should seek qualified professional help when needed.
